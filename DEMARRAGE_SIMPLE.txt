📌 MÉTHODE ULTRA-RAPIDE AVEC pgAdmin
=====================================

ÉTAPE 1 : pgAdmin
-----------------
1. Ouvrir pgAdmin
2. Se connecter avec mot de passe : senecarte
3. Clic droit sur "PostgreSQL 17" → "Query Tool"
4. Ouvrir le fichier : setup-postgres.sql
5. Copier TOUT le contenu
6. Coller dans Query Tool
7. Cliquer sur ▶ Execute (F5)
8. Voir : "Query returned successfully" ✓

ÉTAPE 2 : PowerShell
--------------------
cd "c:\Users\hp\Downloads\magatte_niang_plateforme"
npx prisma generate
npx prisma db push
npx tsx prisma/seed.ts
npm run dev

ÉTAPE 3 : Navigateur
--------------------
Ouvrir : http://localhost:3000

===============================================
  EN CAS DE PROBLÈME
===============================================

❌ "Authentication failed"
   → Vérifier mot de passe : senecarte
   → Redémarrer PostgreSQL dans Services Windows

❌ "Port 3000 in use"
   → npm run dev -- -p 3001

❌ Pages vides
   → npx tsx prisma/seed.ts
   → Vérifier données dans pgAdmin

❌ Erreur TypeScript
   → npm install
   → npx prisma generate

===============================================
  AIDE RAPIDE
===============================================

Voir les données :
   npx prisma studio
   (Ouvre http://localhost:5555)

Arrêter le serveur :
   Ctrl + C dans PowerShell

Redémarrer :
   npm run dev

Réinitialiser la base :
   npx prisma db push --force-reset
   npx tsx prisma/seed.ts
